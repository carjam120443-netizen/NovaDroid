# NovaDroid

A custom Android operating system based on AOSP.

## Project information

- Version: 0.1.0
- Foundation: AOSP
- Interface: Stock Android
- Architecture: ARM64
- Status: Early development

## Goals

- Build from AOSP
- Customize Android branding
- Develop custom system features
- Support compatible Android devices
- Eventually produce flashable ROMs

## Disclaimer

NovaDroid is an independent project and is not affiliated with Google.
